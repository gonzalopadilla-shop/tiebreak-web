# Tiebreak · Web del restaurante

Web y carta pública para móviles y códigos QR de mesas. Este repositorio contiene solo los archivos públicos del navegador y las imágenes publicadas de la carta; no contiene usuarios, reservas, datos de personal ni claves. La aplicación de gestión y su servidor se mantienen en el repositorio privado.

Las solicitudes de reserva se guardan a través del servicio de reservas de Tiebreak. Continúan siendo de demostración; los correos siguen pendientes de configuración.
